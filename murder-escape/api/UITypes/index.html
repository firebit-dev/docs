UITypes

Holds types for UI features — the payload shapes for the shared notification, hint and dialogue surfaces.

These are all "show something to the player" requests. Any code, client or server, can build one of these and hand it to the corresponding controller without knowing how that surface is rendered.

Portrait image asset id

DialogData​

</>
interface DialogData {
text: string--

Line to type out

persist: boolean?--

Keep the box open after the line finishes

timeAfterTypewriter: number?--

Seconds to hold the completed line before advancing

speaker: string?--

Key of a SpeakerData; narration when omitted

position: "top" | "bottom" | "center" | "left"?--

Where the box is anchored

hideClose: boolean?--

Remove the close button

hideSkip: boolean?--

Remove the skip-typewriter affordance

options: {string}?--

Turns the line into a choice prompt

pulsedOption: string?--

Option to highlight, e.g. during onboarding

yield: boolean?--

Block the caller until the line is dismissed

}

One line of dialogue, optionally with choices.

Setting yield makes the call block, which is what lets a scripted sequence be written as straight-line code. Supplying options turns the box into a prompt; hideClose and hideSkip are how a sequence forces the player to actually read or answer.
