Rng

Tiny deterministic PRNG (32-bit xorshift) with a Roblox Random-compatible surface (NextNumber, NextInteger), so it drops into anything that takes a Random (e.g. PoissonDisk). Use it when the SAME seed must yield the SAME stream every run — per-chunk procedural placement that has to look identical across server restarts and across clients. 

local rng = Rng.new(seed)
rng:NextNumber()      -- [0, 1)
rng:NextInteger(1, 6) -- inclusive both ends
