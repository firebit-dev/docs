CosmeticService

This item only works when running on the server. Server

CosmeticService — owns cosmetic ownership/gift/equip behaviour and the always-on hip holsters. Lives outside the legacy ItemProcessor pipeline (which is being phased out).

Ownership lives in profile.inventory — the same [ItemRecord] array every other item type uses — checked via InventoryUtil; the equipped selection lives at inventory_equipped[<slot>] and is written through ProfileService:equipItem.

Every character wears one holster per entry in HOLSTERS: the equipped knife skin on the right hip and the equipped gun skin on the left hip, resolved through Gearkit.Catalog.resolveModel so an unowned or missing skin falls back to the base gear model. Holsters are a lobby display: a holster turns invisible (particles stopped) while that gear's Tool is in the character's hands, and both are hidden for the whole round (RoundTag), so no hip weapon or aura shows mid-round.

Ownership and equips persist across a rejoin because FeatureFlags.SaveInventory is on; with it off, ProfileService empties inventory and inventory_equipped at load.

giftSkin​

</>
CosmeticService.giftSkin(
player: Player,--

recipient

itemId: string--

skin id, must exist in Data/Cosmetics/Skins

) → boolean--

false when the id is not a known skin

Grants a skin to the player and equips it. Used for first-session starter gifts (see Data/Cosmetics/Defaults.luau) and any other server-side handout flow (rewards, codes, etc.). The holster refreshes through ProfileService.ItemEquipped.

Idempotent: a re-gift simply re-equips without erroring. Returns false if the itemId isn't a known skin.

applyToCharacter​

</>

) → ()

Rebuilds every hip holster on the player's current character from their equipped skins. Idempotent; bound to CharacterAdded by CosmeticService.init so holsters survive respawns.

Tells every client to play the killer's equipped kill effect at the victim's position. Equipping checks ownership and an equipped item can't be sold, so the equipped id is trusted as owned.

init​

</>
CosmeticService.init() → ()

Boots the service: holsters every player already in the server, rebuilds them on every spawn and on every skin equip, and hands out the default weapon skins on PlayerService.PlayerLoaded. Also publishes each player's equipped pets, title and nametag on load and whenever those slots change.
