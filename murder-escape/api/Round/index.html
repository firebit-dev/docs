Round

dormant

Documentation-only container for the types that describe a single round of a minigame while it is being played — as opposed to Minigames, which holds the static configuration vocabulary.

A round is one playthrough of one GameMode on one Map, owned by GameService and executed by a BaseGameMode subclass. During a round the mode tracks participants, RoundTeams, per-player scores, and a winner list made of RoundWinner entries; on completion those winners are paid out using the mode's reward config, scaled by any gamepasses the player owns (see RoundPlayerPassesOwned).

Gated by FeatureFlags.Minigames — disabled by default; per-project forks enable it deliberately.
