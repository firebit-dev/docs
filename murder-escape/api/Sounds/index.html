Sounds

Resolves a sound from a flexible path and hands back a ready-to-play Sound.

A Path is either a dotted path into SoundService ("UI.Click"), a raw asset id number, or an rbxassetid:// string, so callers can name a curated sound or drop in an id without branching.

Tree paths are not cloned

A dotted path returns the Sound living under SoundService itself, not a copy. Playing it twice in quick succession restarts the one instance rather than overlapping, and any property you set on it sticks for every later caller. Numeric ids build a fresh parentless Sound each time.

PlaySFX is the higher-level wrapper most gameplay code should reach for.

Overrides the sound's volume

Overrides applied after the sound is resolved. Both are only applied when truthy, so volume = 0 and loop = false leave the existing value alone.

Functions​

get​

</>
Sounds.get(
path: Path,--

Sound to resolve

options: SoundOptions?--

Volume and loop overrides

) → Sound?

Resolves path to a Sound without playing it, or returns nil if nothing matches.

The result is not parented, so parent it (or call Sounds.play) before it will be audible — except for tree paths, which return the already-parented shared instance.

play​

</>
Sounds.play(
path: Path,--

Sound to play

options: SoundOptions?--

Volume and loop overrides

) → Sound?

Resolves path and plays it immediately, returning the Sound so the caller can stop it or wait on Ended.

Returns nil when the path does not resolve — a missing sound is not an error. Nothing is cleaned up for you; a non-looping sound created from an asset id is left for the garbage collector once you drop the reference. 

Sounds.play("UI.Click")
Sounds.play(1234567, { volume = 0.5, loop = true })

use​

</>
Sounds.use(

Sound to resolve

options: SoundOptions?--

) → (
() → ()?,
Sound?
)--

Play callback and the resolved sound

Hook-style variant: resolves the sound once and returns a play callback alongside it, so a component can prepare a sound at mount and trigger it on demand.

Returns nothing at all when the path does not resolve, so destructure defensively.

local playClick = Sounds.use("UI.Click")

button.Activated:Connect(function()
	if playClick then
		playClick()
	end
end)
