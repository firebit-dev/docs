Murder Escape

Round-based murder mystery game for Roblox, built on the firebit core framework (ported from firebit-dev/core v0.3.0).

One player is the Murderer, one is the Sheriff, everyone else is Innocent. The Murderer must kill everyone before the Sheriff stops them. A Sheriff who shoots an Innocent dies and drops their gun — only an Innocent can pick it up.

Stack​

  • Rojo + Wally + aftman toolchain
  • Bootstrap service/controller init framework
  • React (jsdotlua/react) UI with a custom router
  • ProfileDB + Replica data persistence
  • dig1t/red networking
  • Round engine: BaseGameMode + GameService (modes auto-discovered from src/Server/Features/Minigames/GameModes/, maps from ServerStorage.Maps)

Development​

aftman install
npm install
npm run dev   # build murder-escape.rbxl, open Studio, start rojo serve

See CLAUDE.md and docs/PROJECT.md before working in this repo.

Cloning​

This repo has a private submodule at vendor/assets (firebit-dev/assets), so you need read access to it.

git clone --recurse-submodules git@github.com:firebit-dev/murder-escape.git

Already cloned without it:

git submodule update --init
